# 更新公告

**欢迎对本项目提出建议和质疑**

0.4.10 发布之后，0.5.0 ~ 0.6.0 期间未单独发布发行版，本次 **0.6.1 发布版一次性包含这六个版本的全部改动**（0.5.2 版本号未使用，期间改动随 0.5.3 一并计入），下面按版本逐段列出。

## 更新总览

- **0.6.1 公共字典收尾**：H 场景公共字典词条译法扩充；版本号统一收口，作为本期限定发行版，无功能改动。
- **0.6.0 Agent 体系定型 + 使用指南 + 翻译质量大版本**：Agent 能力统一走外置 dsh + MCP（工具扩至 22 个 = 14 只读 + 8 写，新增 8 个写工具与 H 门禁）；新增内置使用指南体系；术语提取断点续跑与疑似 H 分库；冗长/节奏检测体系落地并重构判据；单轮对话模式推广至修复/改进轮；阶段 8 统一编排。
- **0.5.4 全局分析重排与路线图工作台**：新增路线分析 / 全局汇总双后端，全局分析后置到剧情路线图之后逐路线聚焦；任务支持文件子集过滤；移除内置简易 agent 改外置 dsh 预设；「后端配置」术语统一为「API 配置」。
- **0.5.3 校对与设置页改版**：项目设置页重设计为双栏设置中心；新增词语色彩复核后端；semcheck 输出具体原因；新建项目支持自定义位置；全局分析注入人名替换表校正角色名。
- **0.5.1 MCP 初版与必崩修复**：MCP 工具层与 stdio 服务落地（11 个只读检索工具）、顶部连接指示灯；修复 0.5.0 完整流水线启动必崩的 `NameError` 与探活「请求超时」假故障。
- **0.5.0 流水线编排能力**：每阶段独立后端（`stageBackends` 11 键）；阶段清单单一真源；全局分析支持文件子集与按字段覆盖；提示词注入块可配置；H 档位阈值与禁用词表可配。
- **0.4.10 大文件重构**：`server.py` / `LLMTranslate.py` / `ReviewPage.tsx` / `styles.css` 四大文件拆分，全仓超 2000 行代码文件清零，对外行为零改动（详见上一期公告）。

## 0.5.0 流水线编排能力

**阶段清单单一真源**：`pipeline_stages.py` 统一维护 9 阶段清单（含依赖关系与跳过原因预告），前端步骤条改由 `/api/pipeline-stages` 拉取，历史「阶段 4.5」小数序号消失，阶段顺序与文案前后端不再漂移。

**每阶段独立后端**：`common.stageBackends` 由 4 键扩为 11 键，元数据 / 全局分析 / 术语提取 / 翻译 / 校对等每个阶段均可指定独立 API 配置，支持「阶段自身 → 回退槽位 → 任务主配置」三级回退；任务启动时对引用做 fail-fast 校验，`/check-model` 支持分阶段检测。

**全局分析支持文件子集与按字段覆盖**：新增 `internals.pipeline.globalPromptFiles`（指定参与全局分析的文件子集）与 `globalPromptMergeFields`（仅覆盖指定字段），子集分析结果与全量分析合并时空值不覆盖，不传子集时行为与旧版完全一致。

**提示词注入块可配置**：`internals.promptBlocks` 提供翻译规范 / 术语表 / 剧情元数据 / 批次元数据 / 全局分析五块开关；关闭的块按空串替换占位符，模板结构不破坏。

**H 档位阈值与禁用词表可配**：`internals.hLevels.{tension,intimate,explicit}` 三档阈值与 `internals.hForbiddenWords` 禁用词注入均可配；字典分流、批次注入与校对界面 H 区间全链路口径一致。

**剧情路线图按「文件归属」逐路线梳理节点剧情**：`internals.plotroute.routeMode = routesOnly` 时以既有路线图的文件归属为固定约束，只让 LLM 逐路线汇总「节点剧情」，mermaid 拓扑与文件归属绝不重划。

## 0.5.1 MCP 初版与 0.5.0 必崩修复

**MCP 工具层落地**：新增 MCP 检索层与 stdio 服务（构建随包分发 `galtransl_mcp.exe`），提供 11 个只读检索工具（项目 / 缓存 / 问题 / 元数据等），外部 agent 可直接挂载查询翻译现场；新增心跳与 `/api/mcp-status` 连接状态端点，顶部状态栏显示 MCP 连接指示灯（绿 = 有 agent 连接，灰 = 无）。`docx/MCP接入指南.md` 与 galtransl-mcp 技能同步落地。

**修复 0.5.0 完整流水线启动必崩**：0.4.10 拆分时 `_run_full_pipeline` 的 re-export 遗漏，函数体内的全局名查找绕过 `__getattr__` 兜底，启动完整流水线必抛 `NameError`（1602 个测试全绿也没抓到）。修复补齐导入，并把契约测试从 `hasattr` 改为 `vars()` 断言，堵住同类回归。

**其他修复**：模型输出慢时模型检测不再报「请求超时」假故障（后端超时封顶 + 前端放宽）；H 禁用词注入不再因 DictWordMatcher 词表导致翻译报错；全局后端配置写路径打通；`backend_profiles.yaml`（含 API 密钥）加入 gitignore 不入库。

## 0.5.3 校对与设置页改版

> 0.5.2 版本号未使用，期间的改动随本版一并计入。

**项目设置页重设计为双栏设置中心**：左侧分区导航 + 搜索过滤，右侧卡片与字段行重绘，带未保存徽标。

**新增词语色彩复核后端 ForToneCheckAgain**：对色彩命中句做二次复核；统一问题修复单独执行改为复用 afterTranslation 的 fix 条目类型，独立后处理后端改表驱动分发，修复「单独执行连带触发全部后端」的问题。

**semcheck 输出具体原因**：语义检测给出具体问题说明；换行位置异常允许破折号；语义 / 色彩检测与复核轮提示词加缓存头（固定任务说明前置，命中提示词缓存省 token）。

**全局分析注入人名替换表**：`[NameTable]` 占位符注入项目人名对照并按表校正角色名（`inject_name_table` 可关）。

**其他**：新建项目支持自定义位置（不再限制在应用目录内）；术语提取提示词本地化并支持详细备注，字典页支持 Ctrl+S 保存；翻译控制台速度单位改为条/分钟；元数据值框随内容自动撑高；移除剧情路线图可视化编辑，回归源码 / 双栏 / 预览三视图。

## 0.5.4 全局分析重排与路线图工作台

**流水线重排——全局分析后置**：全局分析移到剧情路线图之后执行，新增 `ForRouteAnalysis`（按路线图逐路线生成局部游戏分析分片，单路线超限时按文件分块依次分析并合并）与 `ForGlobalAnalysis`（融合路线分片产出全量分析），分析更聚焦剧情主线；前端项目设置 / 新建向导同步适配。

**路线图工作台**：mermaid 只渲染 + 矩形回退、右键多选、agent 对话与执行终端；新增文件 / 批次元数据文本检索（`POST /metadata/search`）。

**任务支持文件子集过滤与按任务配置覆盖**：`file_filter` / `config_overrides` 可在任务级覆盖项目配置。

**移除内置简易 agent**：Agent 能力改由外置 dsh + MCP 提供，新增 dsh 预设包。

**其他**：H 禁用词裸字改环视正则（消除「逼」「操」等子串误报），禁用词新增「余裕」；「后端配置」术语统一为「API 配置」（前端 + 后端 + 文档）；Ctrl+S 全局保存注册表；审查收口（cancelled 终态、互斥补测、竞态守卫）。

## 0.6.0 Agent 体系定型、使用指南与翻译质量

**Agent 能力统一外置**：程序不再内置 Agent，全部经 MCP 对外提供；工具扩至 **22 个（14 只读 + 8 写）**。新增写工具：路线图 / 元数据写入与提交 / 停止任务、缓存条目跳检与备选交换、缓存条目译文字段改写，项目字典（术语表 / 译前 / 译后）读写工具接入。**H 门禁**：内容写入类写工具受 H 门禁约束，设置页可开关门禁并禁用 MCP 工具；L3 路径白名单硬化，写工具拒绝非项目目录。MCP 检索支持上下文窗口、`field=all_fields` 全字段模式与负数倒数 offset；向 agent 下发只读声明与硬性约束。dsh 预设改单一真相源 + home 层 include 交付，并升级为一键安装 bundle。

**内置使用指南**：新增 `guides/` 使用指南体系（`/api/guides` 只读端点，随发布包分发），帮助菜单三项接通真实行为，指南视图 + 首页上手引导，补 9 篇指南内容；翻译控制台流程说明接入指南入口，并细化校对审核方法（问题筛选与修复、AI 判定与精修、角色一致性核对）。

**术语提取（gendic）增强**：断点续跑分片缓存与 worker 槽位绑定显示；疑似 H 术语独立生成 `_h.txt` 并登记 `gpt.dict` 生效；提取提示词新增「禁止收录」小节（龙套人名 / 拟声词 / 普通物品）；公共字典批量增删与日志降噪。

**翻译质量——冗长 / 节奏检测体系**：新增节奏冗长检测与「节奏单一」问题检测；冗长检测判据重构为同源二译 / 无源增补 / 跨行重复，复核轮改否决式；提示词精简（首轮 -38%、复核 -26%）；节奏豁免覆盖对白软重复、拟声词、幅度门槛等，压掉多类系统性误报；检测轮丢弃回显行与无证据命中，异常批次作废留痕。

**翻译质量——上下文与复核**：单轮对话模式推广至修复 / 改进轮（每批独立完整请求）；单轮历史注入三值化（`restoreContextMode: none / lines / batches`）；复核轮把首轮具体原因注入输入行供 AI 针对性核实；问题修复 / 复核轮输入最前附带问题句前后上下文；H 区间批次指导强化冲击力要求，非 H 区间强化画面感要求。

**流水线与缓存**：阶段 8 统一编排——全部文件翻译完成后执行后处理链，断点标记防重启重复，独立后端跑完自动重检；缓存写删前自动快照备份；重检范围与问题统计口径统一；元数据两阶段新增行数阈值 `metaMinLines`（默认 20，行数不足的文件不生成元数据）；换行修复改自由调整口径并按配置注入阈值。

**校对体验**：校对页 AI 精修落地（`stageBackends.proofread` 槽位生效）；结果预览统一入口（补齐 10 个后端的预览缺失）；TTFT 状态灯新增完成态并适配深色模式；翻译后端下拉改为搜索 + 分组选择器；校对页顶部工具栏两行分组。

**请求治理**：`apiMinIntervalSec` 节流改 (endpoint, token) 进程级时隙预占，修复多实例首请求绕过与并发同睡同醒成簇，新建项目默认 0.5s；重试退避统一 1s 下限；移除在途并发闸，熔断默认关闭。

**其他**：新建项目默认 afterTranslation 流程调整为 fix（残留日文 / 换行异常 / 单句过长等）→ semcheck → tonecheck 并更新默认问题清单，`gpt.swapFixToCurrent` 默认开启；全角文件名 NFKC 归一匹配全链路接入；输入枚举跳过 `_` / `.` 开头子目录；并行后端补齐运行时并发上报；README 补齐 MCP 章节，工具面静态文本同步至 22 工具。

## 发布包内容与 Agent 接入

发布包分三部分：

1. **本体**：解压后直接运行 `GalTransl Desktop.exe` 即可使用，便携版无需安装。
2. **MCP 服务**：`backend/galtransl_mcp.exe`，供任意支持 MCP 的客户端（Claude Desktop 等）接入——在客户端配置的 `mcpServers` 中加入 `{"galtransl": {"command": "<发布目录>/backend/galtransl_mcp.exe"}}` 并重启客户端。检索类工具即插即用，任务启停等 4 个作业域工具需 GalTransl 后端在运行；随包 `skills/galtransl-mcp/SKILL.md` 是接入 agent 必读的约束与禁看清单，H 门禁与工具开关在 GalTransl 设置页调整。
3. **dsh 外置预设**：dsh（DeepSeek Harness）的官方 GalTransl 预设不随包分发，请从项目仓库 `agents/dsh-preset/` 目录获取——在 dsh 的「设置 → 插件 → 安装本地插件」中选中该目录一键安装，新建会话后把 Agent 预设切到 `GalTransl`。该预设把 agent 工具面收窄为「仅 GalTransl MCP 工具」，适合把校对、词典维护、路线图等交给外置 agent 并行处理。
