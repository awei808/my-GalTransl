## 四、验收中发现并修复的问题

### 问题 1：`globalPromptMergeFields` 字段名全无效时静默失效（已修）

**复现**：用户配置 `globalPromptMergeFields: ["剧情概述2", "错别字字段"]`（字段名写错）。

**根因**：
```python
# 修复前（llm_pipeline.py）
if isinstance(raw_fields, list) and raw_fields:
    merge_fields = [x for x in raw_fields if x in MERGE_FIELD_KEYS]
else:
    merge_fields = None
```
过滤后得 `[]`，且 `[] is not None` → 传入 `merge_global_prompt` 后 `target_fields = ()` → **一个字段都不覆盖**。
用户观感：改了配置，全局分析结果完全没变，**无任何提示**。

**修复**：过滤后为空则回退 `None`（等价"未指定"= 覆盖全部）并记 `LOGGER.warning` 列出可用字段名。

**验证**：新增 `MergeFieldsResolutionTests` **4 例**（全有效透传 / 全无效回退 None / 部分无效保留有效 / 空与 None 均表覆盖全部）。测试文件 28 → **32 passed**。

### 问题 2：`ForGlobalPrompt.py` 3 行连续注释（已修）

计划书要求「连续 `#` 注释不得超过 2 行」，`ForGlobalPrompt.py:622-624` 违反。已压缩为 2 行，语义不变，28 passed 保持。
