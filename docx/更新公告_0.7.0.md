# 更新公告 0.7.0（预发布）

> **预发布版本**：核心功能可用；本地 n-gram 语域检测因人工金标评估未达可用标准，本版未启用（入口已移除，实现与金标保留）。

## 新增

- **流水线低代码自定义**：项目设置 → 完整流水线 → 自定义步骤（`internals.pipeline.steps`）。可按顺序增删阶段与 AI 初步处理后端，`fix` 条目支持问题类型组合且同一后端可多次出现。
- **中文通顺检测**（`fluencycheck` / `fluencycheckagain`）：规则初筛命中后送 AI 判定，标记不符合现代汉语自然表达的句子并附「等长或最多多 2 字」的替换建议；复核轮按否决式撤销误报（角色口癖、正当强调、H 场景拟声/断续可接受）。默认后处理链不启用，需在「AI 初步处理」里勾选。
- **外置 Agent 预设扩展**：新增子代理能力；构建同时产出 MCP、Skill、dsh 预设、预设明文四个 Agent 包。

## 改进

- 通顺检测提示词改为自然度优先、补充 H 场景语体，初筛规则降误报；新增 24 句 gold set 离线回归。

## 本版未启用（下线）

- **本地 n-gram 语域检测**（`ngramcheck`）与问题类型「语域异常」：前端选项、后处理白名单、流水线步骤、问题类型目录、修复规格、配置项 `gpt.ngramIndexPath / ngramThreshold / ngramLambda`（模板不再生成）全部移除。
- 旧项目配置里残留的 `ngramcheck` 与「语域异常」会被安全忽略并各告警一次，不会中断翻译（0.7.0 起配置解析、问题类型读取、设置页载入均已加容错）。

## 已知问题

- 旧项目若曾在「问题检测类型」里勾选「语域异常」，设置页不再显示该项，也不会中断检测；只有**改动任意勾选项并保存**后才会从 config.yaml 移除（不动勾选直接保存仍原样保留，不影响运行）。
- 旧缓存可能残留 `ngram_issue` 字段与「语域异常」问题文本，仅作展示，不再参与检测与修复。
- 旧项目配置里的 `gpt.ngram*` 三个键会出现在设置页「未归类设置」组（无专门迁移提示），可手动删除。
