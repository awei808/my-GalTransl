# 开始使用

从零翻译一个游戏，完整流程分四步：

1. **新建（或打开）项目** — 首页「新建项目向导」按步骤创建项目目录；
2. **配置 API** — 在「API 配置」中添加大模型接口（地址 + 密钥 + 模型）；
3. **启动翻译** — 导入剧本后进入「翻译控制台」启动流程，各阶段自动串联；
4. **校对与输出** — 在「校对审核」检查译文，最后「构建输出」得到成品文件。

## 第 1 步 · 新建项目

首页点「新建项目向导」，向导会依次让你填写项目名、导入剧本文件、选择翻译引擎与目标语言等。已有项目用菜单「文件 → 打开项目」选择项目目录（含 `config.yaml` 或 `config.inc.yaml` 的文件夹）。

## 第 2 步 · 配置 API

左侧图标栏「设置」区域或菜单「翻译 → API 配置」进入：

1. 点「新建配置」，填入接口地址（如 `https://api.deepseek.com/v1`）、模型名与密钥；
2. 点「拉取模型」可从接口拉取可用模型名（需地址与密钥正确）；
3. 在项目配置的「翻译后端总设置」中选择使用哪个 API 配置。

## 第 3 步 · 导入并翻译

项目创建时即可导入剧本；之后也可在项目配置页导入。进入「翻译控制台」：

- 选择翻译后端（一般保持 `ForGal-full-pipeline` 完整流水线）；
- 可先点「检测可用性」确认模型连通；
- 点「启动流程」，界面实时显示当前阶段、进度、速度与各 worker 状态。

## 第 4 步 · 校对与输出

翻译完成后进入「校对审核」逐句检查：处理「疑似错误」标记、采纳备选译文、直接修改译文。满意后「构建输出」生成 `gt_output/` 下的成品文件。

## 遇到问题

- **翻译不动 / 报错**：先在翻译控制台点「检测可用性」排查接口；再看菜单「翻译 → 打开日志」。
- **想调翻译风格**：项目配置里的「翻译规范文件」与「提示词模板」。
- **中途停止**：控制台点「停止翻译」，进度已缓存，下次启动会续翻。
