# 翻译控制台

翻译任务的启动与监控中心。

## 流程完成情况（9 阶段）

选择 `ForGal-full-pipeline` 完整流水线时，以下阶段自动串联执行：

| 阶段 | 名称 | 做什么 |
|---|---|---|
| 0 | 输入数据校验 | 检查剧本 JSON 的格式合法性 |
| 1 | 文本无损压缩 | 压缩全文，供后续全局分析使用 |
| 2 | 构建术语表 | AI 提取术语生成 GPT 字典（已有非空字典可跳过） |
| 3 | 生成文件级元数据 | 逐文件总结角色 / 剧情 / 标签，翻译时注入 |
| 4 | 生成剧情路线图 | 生成剧情路线，供分路线分析 |
| 5 | 生成全局游戏分析 | 按路线分析再汇总，产出全局设定档案 |
| 6 | 划分翻译区间 | 给批次标注视角 / 氛围 / H 强度等 |
| 7 | 翻译执行中 | 正式翻译，产出译文缓存 |
| 8 | AI初步处理 | 译文改进、换行修复、残留日文修复、语义复核等后处理 |

已生成过的产物默认跳过；可在项目配置中开启强制重生成。也可以只运行某个独立后端（如单独重跑「生成全局游戏分析」）。

## 界面元素

- **项目统计**：总行数 / 已翻译 / 进度 / 失败条目 / 问题条目；
- **速度与 ETA**：最近 1 分钟翻译行数，及预计剩余时间；
- **并发指示**：活跃 / 已配置的 worker 数；
- **文件进度**：逐文件显示当前阶段与状态（阶段方块亮起表示已完成该阶段）；
- **步骤指示器**：顶部显示 9 阶段当前位置；
- **状态灯**：各 worker 流式首字延迟，异常时变色提示。

## 常用操作

- **启动流程**：选择后端 →（可选）检测可用性 → 启动；
- **停止翻译**：随时可中断；已完成部分写入缓存，下次启动自动续翻；
- **查看日志**：菜单「翻译 → 打开日志」。
