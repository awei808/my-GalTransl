# 人名与字典

「人名与字典」页集中管理五类译文用词资源，分页签：预处理 / GPT 字典 / 后处理 / 禁用词 / 人名替换。项目字典放项目根目录，公共字典放程序目录 `Dict/`（公共字典对所有项目生效）。

## 人名替换

项目根目录的 `name替换表.csv` / `.xlsx`（两列：`SRC_Name` 原文名、`DST_Name` 译名）。翻译输出时按表强制替换说话人字段（`name`/`names`）的人名；正文中的人名由模型按 GPT 字典与提示词翻译。可用 AI 自动生成并批量翻译人名。

## GPT 字典

格式：`日文|中文|解释`（竖线分隔，三列）。

注入提示词，指导 AI 按指定译名与解释翻译名称、术语。文件名以 `_h` 结尾（如 `GPT字典_h.txt`）表示 H 场景专用词典，`_非h` 结尾为非 H 场景专用；无后缀视为非 H。

## 预处理（译前字典）

翻译前对原文做替换，格式 `查找词|替换词`。常用于规范化变体写法、纠正口齿不清等。

## 后处理（译后字典）

翻译后对译文做替换，格式同为 `查找词|替换词`；另支持条件规则：

```
pre_src/post_src|判断词|查找词|替换词
```

即「当原文/译文包含判断词时，才把查找词替换为替换词」。判断词支持 `re:` 前缀正则（如 `re:接続[詞词]`；`!re:` 取反；`>`/`<` 限定与正则组合时回退字面量匹配）。

## 禁用词

译文出现禁用词会被问题检测标记「用词不当」，分 H / 非 H 场景两套词库。

## 通用规则

- **注释**：仅整行行首 `//` 生效（`#` 不是注释符）；
- **正则**：查找词加 `re:` 前缀（如 `re:あ+|啊`）；非法正则回退字面量匹配；
- **转义**：字段内需要字面竖线时写 `\|`；
- **位置限定（推荐正则写法）**：仅首次替换 → 查找词 `re:(?s)^(.*?)词`、替换词 `\1替换词`（`(?s)` 使匹配跨行、`\1` 保留匹配点之前的原文，替换词中的 `\1` 在文件中写作 `\\1`）；仅开头 → 查找词 `re:^词`；
- **旧式前缀（兼容）**：`^^查找词`（仅开头）与 `1^查找词`（仅首次）为上游遗留写法，引擎仍兼容加载（加载时会提示迁移），卡片视图会自动转为等价正则、保存时落盘正则，新字典请直接使用上面的正则写法；
- 以上位置前缀与正则仅替换 / GPT 类词条支持；禁用词与 H 词库只识别行首 `re:`。
