# 插件与提示词模板

## 插件

插件用于扩展文件格式读写与文本处理，放在程序目录 `plugins/`（全局）或项目根 `plugins/`（仅本项目），每个插件一个目录，内含同名 `.yaml` 清单。

- **文件插件（GFilePlugin）**：自定义剧本格式的读写（如 srt / lrc / vtt / epub），让非 JSON 格式也能作为翻译输入输出；
- **文本插件（GTextPlugin）**：在翻译流水线的前后节点处理文本（如译前清洗、译后规范化）。

「插件管理」页可查看已加载插件的名称、版本、作者与类型。

## 提示词模板

「提示词模板」页可覆盖各翻译后端的 system / user 提示词（按引擎分别配置，未覆盖则用内置模板）。

- 模板中的占位符（如 `[history_result]` 历史上下文位置）需要保留，缺失时后端会警告一次；
- 提示词改动影响翻译风格与格式约束，建议先小范围试翻再全量；
- 与「翻译规范文件」（程序目录 `translation_guidelines/`）配合：规范管文风与措辞要求，模板管任务结构。
