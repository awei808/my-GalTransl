# 关于 GalTransl

GalTransl 是一个利用大语言模型（GPT、Claude、Deepseek、Gemini 等 OpenAI 兼容接口）翻译 Galgame（视觉小说）剧本的桌面工具：读入游戏脚本 JSON，经多阶段流水线（元数据、术语表、路线分析、翻译、质量改进）产出译文，并提供校对审核、字典、查找替换等配套界面。

- 项目地址：<https://github.com/awei808/my-GalTransl>
- 基于原作者 [xd2333](https://github.com/XD2333/GalTransl) 的 GalTransl 个人重构扩展，原项目核心设计归原作者所有。

## 界面导览

| 位置 | 内容 |
|---|---|
| 顶部菜单栏 | 文件 / 编辑 / 翻译 / 视图 / 帮助 |
| 左侧图标栏 | 翻译控制台、校对审核、路线图工作台、人名与字典、构建输出、设置等高频入口 |
| 主区域 | 当前视图页面；校对审核视图另有文件浏览器 / 查找 / 问题侧栏 |
| 底部状态栏 | 后端连接状态与版本号 |

## 常规流程

新建项目 → 配置 API → 启动翻译 → 校对审核 → 构建输出。详见「开始使用」。

## 其他

- 程序的 Agent 能力通过 MCP 对外提供，可配合外置 Agent（dsh）使用，见「MCP 与外置 Agent」。
- 翻译风格由「翻译规范文件」（程序目录 `translation_guidelines/`）与提示词模板控制。
