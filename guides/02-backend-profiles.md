# API 配置

「API 配置」管理大模型接口连接（全局共享，多个项目可复用同一配置）。

## 字段说明

| 字段 | 说明 |
|---|---|
| 配置名称 | 自定义名称，供项目配置中引用 |
| 后端类型 | 兼容 OpenAI 接口的供应商标识 |
| 接口地址 | OpenAI 兼容 API 的 Base URL，如 `https://api.deepseek.com/v1` |
| 模型名称 | 模型 ID，如 `deepseek-chat`；可点「拉取模型」从接口获取列表 |
| 密钥 | 服务商提供的 API Key；可添加多条令牌（每条一个 Key），翻译时轮换负载均衡 |
| 上下文大小 | 模型上下文窗口（token），默认 128000；当前版本仅保存配置，预留给后续版本的上下文压缩 / 用量显示 |
| 流式请求 | 是否流式接收响应（开启可实时显示进度与首字延迟） |

## 在项目里使用

在「项目配置 → 翻译后端总设置」中选择要用的 API 配置；流水线的不同阶段（元数据、全局分析等）也可按后端分别指定不同接口。

## 检测可用性

翻译控制台的「检测可用性」按钮会向所选后端发一条最小请求，验证地址 / 密钥 / 模型三者连通；不通过时启动翻译前会二次确认。

## 常见问题

- **401 / 鉴权失败**：密钥填错或已过期。
- **连接超时**：网络不通。海外服务需在项目配置的代理设置中填写代理；国内服务无需代理。
- **429 限流**：程序会自动退避重试；持续出现可调低项目配置的 `workersPerProject`（并发数）。
- **模型名报错**：不同供应商模型名不同，先用「拉取模型」确认。
